## Execution and security limits

This is source-only publication for inspection and contribution. There is no
approved fresh networked native installation procedure. Default live SDK client
construction is disabled before credential access or HTTP-client creation;
credentials and opt-in flags do not lift the restriction. Offline fixture preview
and verification require an existing, separately approved environment with all
locked inputs already provisioned. See [setup status](release-status.md#local-setup-qualification).

Native certificate-trust qualification remains unresolved. The restriction is
not a TLS correction, an affected-chain rejection result or a security guarantee.
The separate CA-trust prototype is not included. Docker execution remains held;
retained Docker/bootstrap source and historical records are engineering references.

All held A1/A2 successor-base groups remain unresolved (HOLD BOTH; zero final
case dispositions). Gate 2 stays closed and B04 remains open. Source visibility
does not qualify successor images or approve prospect use.

## Distribution and use boundaries

The distribution scope is a GitHub **pre-release** with automatic source ZIP/tar
archives only. No wheels, compiled binaries, dependency/runtime
bundles, Docker images or hosted service are distributed as release assets.
No client/matter processing, prospect demonstration, hosted/production deployment,
legal-quality, privacy, privilege, compliance, security-certification or model
performance assurance is supplied.

Use [Support](../SUPPORT.md) for non-sensitive questions and
[Security](../SECURITY.md) for private reporting. Keep raw security evidence and
confidential material out of public issues and attachments.
