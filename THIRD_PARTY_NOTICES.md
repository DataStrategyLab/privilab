# Third-party notices and sources

The Apache-2.0 project license does not replace component licenses. This index
is reconciled from the existing artifact registry; it is not a new upstream
license audit, a vulnerability assessment or blanket redistribution clearance.
Keep full upstream license/copyright/NOTICE files with any redistributed bytes.

The source-release preparation does not include vendored dependency packages,
managed Python/tools or container images. Reference-only ecosystem mentions do not
import their source/tasks or imply partnership. DSL marks retain trademark rights.

## Scope of this index

The registry records original review dates and source identities. Some licenses
have combined/alternative terms; use the exact artifact and bundled text when
redistributing. Native libraries and Debian packages in a built container require
an actual-image inventory and their own notice review. A project-lock SBOM does
not cover that complete filesystem.

See [licenses/README.md](licenses/README.md), [registry.yaml](licenses/registry.yaml)
and the [pending release status](docs/release-status.md). No rights/security gate
is closed solely because a row is present here.
